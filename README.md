# Productividad Estudiantil - Machine Learning

## 📌 Objetivo

Desarrollar modelos de aprendizaje automático que permitan clasificar estudiantes a partir de sus hábitos, utilizando características como:

- Horas de sueño
- Tiempo en el celular
- Tiempo dedicado a videojuegos
- Hábitos de estudio
- Rutinas diarias

El objetivo es predecir qué estudiantes necesitan intervención debido a su baja productividad, permitiendo brindar atención temprana y reducir el riesgo de deserción académica.

---

## 📊 Dataset Utilizado

El dataset utilizado se encuentra disponible en Kaggle:

🔗 https://www.kaggle.com/datasets/algozee/student-productivity-and-behavior-dataset-20k

### Características del dataset

- Más de **20.000 registros**
- Información relacionada con hábitos y productividad estudiantil
- **18 características** diferentes para el análisis
