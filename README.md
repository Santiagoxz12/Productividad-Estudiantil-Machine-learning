# Productividad-Estudiantil-Machine-learning
objetivo
Desarrollar modelos de aprendizaje automático que permitan clasificar estudiantes a partir de sus habitos, utilizando características como las horas de sueño, tiempo en el celular, tiempo en videojuegos con el fin de predecir los estudiantes que necesitan intervención debido a su baja productividad y así brindar una atención temprana y que el estudiante no entre en riesgo de desertar.
Dataset utilizado
el dataset se encuentra disponible en https://www.kaggle.com/datasets/algozee/student-productivity-and-behavior-dataset-20k cuenta con 20.000 datos de los habitos de estudiantes y 18 caracteristicas.
Modelos Utilizados
Supervisados:

Decision Tree (DT)
Gaussian Naive Bayes (GNB)
Random Forest (RF)
Support Vector Machine (SVM)
Support Vector Regresor (SVR)
Deep Neural Networks (DNN)
No Supervisados:

Clustering

KMeans
DBSCAN
Reducción de dimensionalidad

PCA
t-SNE
